# Security policy

Report a vulnerability privately with GitHub's
[private vulnerability reporting](https://github.com/phawrylak/IntactWarden/security/advisories/new)
(the "Security" tab → "Report a vulnerability"), not in a public issue. Other bugs are ordinary
[issues](https://github.com/phawrylak/IntactWarden/issues).

A vulnerability is above all anything that makes IntactWarden show Verified while unverified code
runs, or lets code that does not match its release run at all. Please include the Firefox version,
the state shown and the state expected, and how to reproduce it.

Only the latest version is supported; every fix is a new release. Problems in Bitwarden or
Vaultwarden themselves belong to those projects. Review of the code by anyone, by hand or with an AI
assistant, is welcome.
